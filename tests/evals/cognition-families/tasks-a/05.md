# Precursor: fam-05-handler-error-mapping

The /session handler maps store failures to HTTP status codes ad hoc. Codify the mapping table in main.go as a function mapStoreError(err error) int returning: 404 for ErrNotFound, 409 for ErrConflict, 400 for ErrInvalidID, 429 for ErrUserAtCap, and 500 for anything else. Use it from every branch of sessionHandler so status codes have one source of truth. (If a store error type does not exist yet in the fixture, treat this as mapping from the known sentinel errors that do exist: ErrNotFound, and leave TODO markers for the others.)
