# Precursor: fam-01-password-reset-invalidation

A user reports that after resetting their password through the admin console, the old session on their phone still works. Fix the password reset flow: add a ResetPassword(userID string) error method to Store in session.go that deletes every session belonging to that user (there is no per-user index, so scan). Wire it nowhere else; the method and its correctness are the deliverable. The existing ErrNotFound semantics are unaffected.
